# Database

Structured hardware data backing the BareBoard site.

| Dataset                | Description                              | Format |
|------------------------|------------------------------------------|--------|
| chips.json             | Chip-to-device mappings                  | JSON   |
| devices.json           | Device catalog                           | JSON   |
| preservation-inventory | Acquired public documents with hashes    | CSV    |
