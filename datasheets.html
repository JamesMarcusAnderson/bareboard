    Manufacturer datasheet libraries

    Can’t find a specific part? Start at the source — every major chipmaker’s public documentation library:

    A

    • Analog Devices — Data converters, amplifiers, RF, power — datasheets for every part
    • ARM — Processor IP documentation and technical reference manuals

    B

    • Broadcom — Networking, storage, and wireless chips — legacy Avago/Broadcom docs

    C

    • Cypress (now Infineon) — PSoC, USB controllers, memory — search Infineon’s product catalog

    D

    • Diodes Incorporated — Discretes, logic, power management — full datasheet library
    • DSP Group (now Synaptics) — VoIP and voice processors — legacy DSPG docs via Synaptics

    F

    • FTDI — USB-to-serial bridges (FT232, FT2232) — the classic hacker UART chip

    I

    • Infineon — Power, microcontrollers (AURIX, XMC), security chips
    • Intel — CPUs, chipsets, networking — ARK database and technical docs

    L

    • LG Display — Display panels — specs via panel database sites
    • LG Innotek — Camera modules, wireless charging, automotive components
    • Linear Technology (now Analog Devices) — Power management — classic LT datasheets live on at ADI

    M

    • Marvell — Networking, storage controllers, custom silicon
    • MaxLinear — Cable tuners and broadband front-ends
    • MediaTek — Mobile SoCs, Wi-Fi, Bluetooth — limited public docs
    • Microchip — PIC, AVR, SAM microcontrollers — excellent public datasheets
    • Micron — DRAM and NAND flash — full datasheet library
    • Murata — Passives, RF modules, sensors

    N

    • Nordic Semiconductor — nRF Bluetooth/802.15.4 SoCs — superb public documentation
    • NXP — i.MX, Kinetis, LPC microcontrollers — full public docs

    Q

    • Qualcomm — Snapdragon, Wi-Fi (Atheros), modems — mostly NDA-gated
    • Qorvo — RF front-ends, power amplifiers

    R

    • Raspberry Pi — Official RP2040/RP2350 datasheets and hardware docs — fully open
    • Realtek — Ethernet, Wi-Fi, audio codecs — sparse public docs
    • Renesas — Microcontrollers, power, analog
    • ROHM — Power, discretes, LSI

    S

    • Samsung Semiconductor — DRAM, NAND, SoCs, displays — product specs and select datasheets
    • Silicon Labs — Wireless MCUs, timing, isolation — good public docs
    • SK hynix — DRAM and NAND flash
    • Sony Semiconductor — Image sensors — the IMX series datasheets
    • STMicroelectronics — STM32 MCUs, sensors, power — excellent public documentation
    • Synaptics — Touch, VoIP (ex-DSP Group), edge AI

    T

    • Texas Instruments — The gold standard — every part has a public datasheet, app notes, and reference designs
    • Toshiba — Memory, discretes, motor drivers

    Missing a datasheet? If you can legally share one for a chip we’ve documented, let us know.

    BareBoard Legal Framework & Declarations

    • No AI training: All text, findings, and original photography on this site are copyrighted. Automated scraping for AI model training is prohibited. Crawlers that ignore robots.txt are trespassing.
    • Educational nature: BareBoard operates exclusively as a non-commercial, open educational resource. All material is compiled for academic evaluation, hardware preservation, and technical literacy under 17 U.S.C. § 107 (fair use).
    • Zero-leak / no-binary clause: This site does not host, distribute, or mirror proprietary firmware binaries, encrypted operating system keys, or weaponizable exploits. Documentation covers only the public, physical realities of circuit hardware.
    • Property verification: Every hardware autopsy is performed on personally owned, legally acquired equipment. No rented or third-party infrastructure is used.
    • Public source sourcing: Comparative and regulatory data is aggregated from official public filings, including the U.S. Federal Communications Commission equipment authorization database.
