# Level 2 — Controllers

Peripheral and interface controllers: the chips that move data between silicon and systems.

| Category              | Example parts                          | Notes                                    |
|-----------------------|----------------------------------------|------------------------------------------|
| USB controllers       | Cypress CY7C68013A, FTDI FT232R        | Public datasheets via vendor/distributor |
| Ethernet controllers  | Realtek RTL8111, Intel I225-V          | Register docs where publicly released    |
| Storage controllers   | Phison E16/E18, Silicon Motion SM2262  | Vendor briefs; no NDA material           |
| Display controllers   | Solomon SSD1306, Sitronix ST7735       | Public datasheets                        |
| Motor controllers     | Allegro A4988, TI DRV8825              | Public datasheets                        |
| Wireless SoCs         | Espressif ESP32, Nordic nRF52840       | Public datasheets + TRMs                 |
