The Autopsy Report

We can’t open their hardware, so we open our findings.

Device-by-device hardware analysis, published free. Each report is built from our own bench work — verified findings only, uncertainty dated and marked.

Device #001

Xfinity XB3

Status: published — read the full report.

  • J3 UART: unpopulated 4-pin header located next to the main SoC. Boot log captured read-only — no console access was ever obtained.
  • Wi-Fi-disable mod: a published third-party hardware writeup (TPS54328 regulator enable line) documented as reference for radio interference. Not performed on our unit.
  • Bridge mode: unit placed in bridge mode via the admin panel and paired with an Apple AirPort Time Capsule as the actual router.
  • This is not a power-optimization project — the Wi-Fi work was about eliminating radio interference, full stop.
  • No firmware was extracted, modified, or redistributed. All work performed on a personally owned, pre-paid unit.
